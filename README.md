# Screaming Penguin

Screaming Penguin is a config-driven, automated Debian installer delivered as
the canonical raw `.img` artifact (Linux-friendly). The hybrid `.iso` path has
been pruned from this repository; any future ISO media lives in the separate
Ouroboros side project.

See the `docs/` directory for full usage guides:

- `USING_IMG.md`
- `USING_ISO.md` *(archives the historical ISO instructions; ISO builds are
  disabled here)*
- `GETTING_STARTED.md`
- `INSTALLER_USAGE.md`
- `CONFIG_REFERENCE.md`

The `.img` artifact ships with a prebuilt CONFIG partition so it is ready for
installer-config.yml right after flashing. ISO-specific instructions only remain
for historical reference and point to Ouroboros for any hybrid media needs.
