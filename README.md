# Screaming Penguin

Screaming Penguin is a config-driven, automated Debian installer delivered as a
bootable USB image. This README will be refined alongside the Phase 7
documentation work.

## Documentation

User-facing documentation for Screaming Penguin is located under the `docs/`
directory:

- `GETTING_STARTED.md`
- `INSTALLER_USAGE.md`
- `CONFIG_REFERENCE.md`
- `SAFETY.md`
- `TROUBLESHOOTING.md`

These documents are currently in skeleton form and will be completed during
Phase 7 Prompt B.
