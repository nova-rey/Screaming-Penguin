# Screaming Penguin — Installer Runtime Specification (Phase 5)

This document defines the architecture and behavior of the Screaming Penguin installer runtime implemented in Phase 5. It is a state-driven system executed inside the initramfs environment on the bootable USB media.

---

## 1. Overview

The installer reads a configuration file under `/config/installer-config.yml`, validates it, prepares the target disk, extracts a root filesystem generated by Phase 4, configures the installed system via chroot, installs GRUB, and writes logs to `/config/logs/`.

The runtime must be fully deterministic, safe, and auditable.

---

## 2. State Machine

The installer follows a linear state machine:

1. **BOOT_INIT**
   - Mount `/config` (FAT32).
   - Initialize logging.
   - Optional audio cue: “Installer ready.”
   - Prepare runtime directories.

2. **LOAD_CONFIG**
   - Parse YAML config.
   - Validate fields:
     - target.disk
     - rootfs.path
     - hostname, locale, timezone
     - user.{name, password_hash or SSH}
     - SSH enable rules
   - Abort on any missing required element.

3. **PLAN_INSTALL**
   - Detect available block devices.
   - Verify target disk exists.
   - Reject if target disk matches the USB boot device.
   - Plan GPT layout:
     - p1: EFI (FAT32)
     - p2: ext4 root
   - Determine boot mode: UEFI, BIOS, or auto.

4. **CONFIRM_INSTALL**
   - If `require_erase_word: true`, prompt user.
   - Require exact match: `ERASE`.
   - Abort if incorrect or missing.

5. **EXECUTE_INSTALL**
   - Partition disk using `sgdisk`.
   - Create filesystems.
   - Mount new system under `/mnt/target`.
   - Extract rootfs tarball.
   - chroot to:
     - configure hostname, locale, timezone.
     - create user, set sudo permissions.
     - configure SSH keys or password.
     - install GRUB for BIOS and UEFI.
     - update-initramfs and update-grub.

6. **FINISH**
   - Write final status to `/config/logs/<timestamp>.log`.
   - Optional audio cue: “Installation complete.”
   - Shutdown or reboot.

---

## 3. Safety Model

The installer environment prohibits:

- Any block device modification outside the declared target disk.
- Any chroot operation outside the extracted rootfs.
- Continuing execution after partial failures.
- Proceeding without required configuration values.

---

## 4. Logging

All state transitions and errors must be recorded in a log stored at:

/config/logs/installer-.log

The log includes:
- timestamped events
- state transitions
- failure codes
- partitioning summary
- GRUB installation output
