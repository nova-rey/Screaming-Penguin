**Changes**
- Added a dedicated `sp_bootstrap_usb_storage` helper that modprobes the USB/SCSI stack, rescans every `/sys/class/scsi_host/host*`, waits up to 2 s for `/sys/block/sd*`, and emits the required `[SP-INSTALLER] usb-storage-scan=begin/complete devices=…` logs before mirroring the helper into the initramfs build tree (`installer/runtime/lib/storage_bootstrap.sh:1`, `build/installer-initramfs/runtime/lib/storage_bootstrap.sh:1`).
- `installer/init/init.sh:80` now sources the helper’s library, and `sp_bootstrap` calls `sp_bootstrap_usb_storage` immediately after `sp_bootstrap_dev_nodes` (`installer/init/init.sh:456`) so the rescan runs during early bootstrap without affecting later probes.
- Config discovery likewise sources the helper and runs it before any probing (`installer/runtime/lib/config_discovery.sh:25`, `:480`), and the BusyBox tests now script delayed `/sys/block/sda` creation as well as a no-op scan to prove the behavior both when USB appears late and when it already exists (`tests/installer/test_config_discovery_busybox.py:112`, `:216`, `:237`).
