**Changes**
- The initramfs builder now extracts the installer kernel version from the configured `vmlinuz-installer` artifact (`tools/build_installer_initramfs.sh:37`), logs the detected identity, and stages only `/lib/modules/<that-kernel>` (with configurable module roots) before failing when the matching directory is missing (`tools/build_installer_initramfs.sh:205`).
- Runtime startup now validates `/lib/modules/$(uname -r)` (or an override) before touching config discovery or rescue, logging a fatal mismatch and exiting early if the directory is absent, then only runs the storage-driver bootstrap after the check succeeds (`installer/init/init.sh:258`, `installer/init/init.sh:785`).
